# Spanish Present-Tense Quiz

Practice the same 14 verbs as span015 with six questions per verb, one for each pronoun group. Each question has four shuffled choices: the correct conjugation and three close spelling distractors. Reflexive verbs include their reflexive pronouns in every choice.

Answers receive immediate feedback. Score 100% to unlock the next verb; restart to reshuffle questions and choices.

Practice online at https://esemmelman.github.io/spa016/ or open `index.html` in a browser. Works offline with no dependencies or build step.
